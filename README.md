# RelocateFlow

A polished, frontend-first relocation planning experience built to demonstrate senior React and Next.js product engineering skills.

## Product concept

RelocateFlow helps skilled professionals plan a move to Europe through a personalized onboarding experience, a relocation readiness dashboard, task and document tracking, budget visualization, city comparisons, and an in-context relocation assistant.

This portfolio project intentionally uses rich mocked data and browser state instead of a database so the focus stays on interaction design, component architecture, responsiveness, accessibility, and frontend execution.

## Highlights

- Conversion-focused responsive landing page
- Five-step personalized onboarding flow
- Data-rich relocation dashboard
- Interactive task completion and assistant panel
- Budget, timeline, city-match, and document interfaces
- Mobile navigation and responsive layouts
- Strict TypeScript and Next.js App Router
- Bespoke design system using CSS variables

## Stack

- Next.js 16
- React 19
- TypeScript
- Lucide React
- Custom CSS design system

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Routes

- `/` — Marketing landing page
- `/plan` — Personalized onboarding
- `/dashboard` — Full mock product dashboard

## Portfolio note

All customer, financial, city, task, and document information is fictional demo data. No database or external API is required.
